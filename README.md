# كلك جميلة — مبيعات وتحصيلات + تطبيق للعملاء

تطبيق أندرويد واحد: بيفتح لوحة المدير لما تدخل بإيميل المدير، وبيفتح تطبيق العميل لأي حد داخل برقم موبايله.

## المدير
- العملاء بكود ثابت يتعدل (من غير تكرار)، بحث بالاسم أو الكود أو الرقم
- صفحة لكل عميل: المسحوب، المدفوع، الباقي، النقط، سجل الحركات بالصور
- بيع بالدوس على المنتجات (كمية وسعر)، مديونية يدوي، دفعة مع البيع، صور
- دفعة مع تحديد الأصناف اللي دفع تمنها (والباقي بيتحسب على الأقدم)
- تعديل الحساب: زوّد / اخصم / حدّد اللي عليه، واستبدال نقط
- فاتورة PDF وكشف حساب PDF يتبعتوا واتساب، ورسالة تذكير بالمديونية
- البضاعة: كمية في المحل، سعر بيع وشرا، تنبيه الأصناف اللي قربت تخلص، رصيد البضاعة
- الرئيسية: الفلوس اللي برّه، المحصّل النهارده والشهر، قيمة البضاعة
- العروض، الطلبات (تسليم الطلب بيسجله على حساب العميل تلقائي)
- حسابات العملاء: إضافة، تغيير كلمة السر، إيقاف، حذف

## العميل
- تسجيل برقم الموبايل وكلمة سر
- العروض اليومية والمعرض، سلة وطلب
- حسابي: الفواتير والدفعات والباقي والنقط (نقطة على كل فاتورة فوق 200، ونقطة على كل دفعة 200 أو أكتر)
- لو المدير ضايفه في الدفتر بنفس الرقم، بيشوف حسابه كله تلقائي
